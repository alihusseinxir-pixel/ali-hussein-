# نظام الرد الآلي باللهجة العراقية

نظام يرد على رسائل الزبائن من **واتساب** و**انستغرام** و**فيسبوك ماسنجر** بشكل احترافي وباللهجة العراقية، ويعرف تفاصيل كل محل (مطعم، عيادة، صالون، متجر...) بشكل منفصل.

## شنو يسوي

- **يرد تلقائياً** باللهجة العراقية، مختصر ومرتب مثل رسائل الواتساب.
- **يعرف كل محل لحاله**: المنيو والأسعار، الدوام، الموقع، التوصيل، العروض، الأسئلة المتكررة. المطعم ما يختلط ويه العيادة أبداً.
- **ما يخترع معلومات**: إذا الجواب مو موجود، يحول المحادثة لموظف.
- **يسجل الطلبات والحجوزات**: طلب أكل، موعد عيادة، حجز طاولة. تظهر باللوحة وتوصل إشعار لصاحب المحل على تلغرام.
- **تسليم لموظف**: إذا الزبون زعلان أو طلب موظف، الرد الآلي يوقف على هاي المحادثة والموظف يكمل من اللوحة.
- **يجمع الرسائل المتتالية**: إذا الزبون دز 3 رسائل ورا بعض، يرد مرة وحدة.
- **لوحة تحكم عربية** تشتغل على الموبايل والكمبيوتر.

## شلون يبيع (مو بس يجاوب)

النظام يشتغل مثل أحسن موظف مبيعات عندك:

| المرحلة | شنو يسوي |
|---|---|
| يفهم الزبون | ما يدز المنيو كله؛ يسأل سؤال واحد (لكم شخص؟ توصيل لو استلام؟) ويرشح |
| يرشح بثقة | يقترح «الأكثر طلباً» بالاسم والسعر ويه سبب يشهّي |
| يكبّر الطلب | يقترح شي واحد مكمل (مقبلات، مشروب، عرض العائلة ويگول كم يوفر). إذا رفض ما يعيد |
| يعالج الاعتراض | «غالي» ← يوضح القيمة أو بديل أرخص. «بعيد» ← الوقت الحقيقي أو الاستلام. «خلي أفكر» ← بدون ضغط |
| يسكّر البيع | أول ما يبين اهتمام يسأل «أسجلك الطلب هسه؟» |
| يحسب صح | الأسعار تنحسب بالكود من المنيو، مو بالذكاء الاصطناعي، فما يغلط بالمجموع |
| يتذكر الزبون | الاسم، العنوان، التفضيلات، الطلبات السابقة ← «هلا مصطفى، نفس طلبك الماضي؟» |
| يتابع | اللي شاف السعر وما أكد، يدزله رسالة تذكير وحدة لطيفة بعد ساعة (ضمن نافذة 24 ساعة مال واتساب) |
| صادق | ما يخترع خصم ولا «باقي قطعتين» ولا استعجال مو حقيقي |

حتى تشتغل هاي الأشياء زين، عبّي باللوحة: **الأكثر طلباً**، **اقتراحات مكملة**، و**العروض**. والمنيو لازم كل صنف بسطر بشكل `الاسم: السعر` حتى الحاسبة تقراه.

تبويب **الإحصائيات** يبينلك: نسبة التحويل، الإيرادات، متوسط الطلب، كم طلب زاد باقتراح من النظام، وكم متابعة رجعت زبون.

## التشغيل على جهازك (5 دقايق)

تحتاج [Node.js](https://nodejs.org) نسخة 20 أو أحدث.

```bash
npm install
cp .env.example .env      # وحط مفتاح ANTHROPIC_API_KEY داخل الملف
npm start
```

افتح `http://localhost:3000`:

1. تبويب **«جرّب كزبون»**: اكتب كأنك زبون وشوف الرد. فيه مطعم تجريبي جاهز (بيت الكبة).
2. تبويب **«معلومات المحل»**: عدّل المعلومات أو أضف محل جديد من زر «+ محل جديد».
3. تبويب **«المحادثات»**: كل المحادثات، وتگدر تستلم أي محادثة وترد كموظف.
4. تبويب **«الطلبات والحجوزات»**: الطلبات اللي سجلها النظام، وتغير حالتها (مؤكد، منتهي، ملغي).

> بدون `ANTHROPIC_API_KEY` النظام يشتغل بوضع تجريبي بردود بسيطة جداً، بس حتى تشوف اللوحة وتجرب الربط.

## ربط واتساب (WhatsApp Business Cloud API)

تحتاج: حساب [Meta Business](https://business.facebook.com)، ورقم موبايل مو مسجل على واتساب عادي (أو تنقل رقم المحل لـ API).

1. ارفع السيرفر على الإنترنت أولاً (شوف «النشر» تحت) حتى يصير عندك رابط `https://...`.
2. ادخل [Meta for Developers](https://developers.facebook.com/apps) ← Create App ← نوع **Business** ← أضف منتج **WhatsApp**.
3. من **WhatsApp ← API Setup** انسخ **Phone Number ID** وحطه باللوحة بتبويب **«الربط»** للمحل.
4. اعمل توكن دائم: Business Settings ← System Users ← Add ← Generate Token بصلاحيات `whatsapp_business_messaging` و `whatsapp_business_management`. حطه بـ `WHATSAPP_TOKEN`.
5. من **App Settings ← Basic** انسخ **App Secret** وحطه بـ `META_APP_SECRET`.
6. من **WhatsApp ← Configuration ← Webhook**:
   - Callback URL: `https://رابطك/webhook`
   - Verify token: نفس قيمة `META_VERIFY_TOKEN`
   - اشترك بحقل **messages**.
7. دز رسالة للرقم من موبايلك، وراح تشوفها باللوحة ويرد عليك النظام.

### انستغرام وماسنجر

نفس التطبيق ونفس رابط الـ Webhook. أضف منتج **Messenger** و**Instagram**، اربط صفحة المحل، اشترك بحقل `messages`، وحط **Page ID** و**Instagram Account ID** بتبويب «الربط»، والتوكن بـ `META_PAGE_TOKEN`. (هذا الجزء مكتوب حسب وثائق Meta بس لسه ما تجرب على حساب حقيقي.)

### إشعارات تلغرام لصاحب المحل (اختياري)

1. بتلغرام افتح `@BotFather` ← `/newbot` وانسخ التوكن لـ `TELEGRAM_BOT_TOKEN`.
2. صاحب المحل يدز أي رسالة للبوت، وبعدين افتح `https://api.telegram.org/bot<التوكن>/getUpdates` وانسخ `chat.id`.
3. حطه باللوحة بتبويب «الربط» ← «تلغرام صاحب المحل».

## النشر على الإنترنت

**الأسهل: Render.com**
1. ارفع المشروع على GitHub.
2. بـ Render: New ← Blueprint ← اختار المستودع. ملف `render.yaml` يجهز كل شي (مع قرص دائم للبيانات).
3. حط `ANTHROPIC_API_KEY` و `META_APP_SECRET` و `WHATSAPP_TOKEN`. كلمة سر اللوحة و `META_VERIFY_TOKEN` تنولد تلقائياً وتلگاها بإعدادات الخدمة.

**أو أي سيرفر فيه Docker:**
```bash
docker build -t raddbot .
docker run -d -p 3000:3000 -v raddbot-data:/data --env-file .env raddbot
```

> بالإنتاج لازم `ADMIN_PASSWORD`، وإلا اللوحة تنقفل. اسم المستخدم أي شي، المهم كلمة السر.

## الكلفة التقريبية

- **Claude**: النموذج الافتراضي `claude-opus-5-5`. معلومات المحل تنحفظ بالكاش، فالرد الواحد كلفته قليلة. إذا تريد أرخص حط `CLAUDE_EFFORT=low`.
- **واتساب**: الرد على الزبون خلال 24 ساعة من رسالته مجاني حسب تسعير Meta الحالي. الرسائل اللي تبدأها انت (عروض) لها كلفة وتحتاج قوالب معتمدة.
- **السيرفر**: Render حوالي 7 دولار بالشهر.

## هيكل المشروع

```
src/
  server.js          السيرفر، الويبهوك، وواجهة اللوحة
  engine.js          يستلم الرسالة ← يلقى المحل ← يولد الرد ← يرسله
  brain.js           تعليمات اللهجة العراقية + معلومات المحل + أدوات الطلب والتحويل
  db.js              التخزين (ملف JSON)
  notify.js          إشعارات تلغرام
  seed.js            المطعم التجريبي
  pricing.js         حاسبة الأسعار من المنيو
  followup.js        المتابعة التلقائية
  channels/
    whatsapp.js      واتساب Cloud API
    meta.js          ماسنجر وانستغرام
public/              لوحة التحكم
test/flow.test.js    اختبار كامل بدون إنترنت (npm test)
```

## المراحل الجاية

1. **الرسائل الصوتية**: تحويل الصوت لنص (مهم بالعراق لأن أغلب الناس تدز فويس).
2. **حسابات منفصلة لكل صاحب محل**: كل واحد يدخل ويشوف محله بس (هسه كلمة سر وحدة للكل).
3. **قاعدة بيانات PostgreSQL** بدل ملف JSON لما يزيد عدد المحلات.
4. **حملات عروض** لزبائن سابقين (تحتاج قوالب واتساب معتمدة من Meta).
5. **اشتراكات شهرية** (SaaS).
